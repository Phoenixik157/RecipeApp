# RecipeApp

Мобильное приложение «Рецепты» — кулинарная книга с поиском по ингредиентам,
геймификацией и QR-кодами. Разрабатывается в рамках семестрового проекта.

## Функционал

- Поиск рецептов по ингредиентам («Что у меня есть?»)
- Режим замены ингредиентов
- Фильтр «Минимум покупок»
- Пересчёт порций
- Свои рецепты (CRUD)
- Статистика и графики
- Геймификация: уровни, XP, дневные лимиты, достижения
- QR-код для обмена рецептами
- Экспорт/импорт резервной копии в JSON
- Тёмная тема

## Стек

- Kotlin, Java
- Android Studio
- Room (SQLite) — локальная БД
- MVVM + LiveData/Flow
- Retrofit — для TheMealDB API
- MPAndroidChart — для графиков
- ZXing — для QR-кодов

## Источники данных

- [TheMealDB API](https://www.themealdb.com/api.php)
- Пользовательские рецепты

## Как запустить

1. Клонировать репозиторий.
2. Открыть в Android Studio.
3. Дождаться синхронизации Gradle.
4. Запустить на эмуляторе или реальном устройстве (min SDK 24).
